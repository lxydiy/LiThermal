# 03 · 构建与运行

## 1. 工具链

项目面向全志 T113-S3（ARM Cortex-A7），使用基于 musl libc 的 OpenWrt 交叉工具链。

- 工具链名称：`arm-openwrt-linux-gcc` / `arm-openwrt-linux-g++`
- 工具链路径变量：`CROSS_CHAIN_PATH`，指向 `toolchain-sunxi-musl/toolchain/bin/`
- 工具链配置：[toolchain.cmake](file:///workspace/toolchain.cmake)

```cmake
set(CMAKE_SYSTEM_NAME Linux)
set(CMAKE_SYSTEM_PROCESSOR arm)
set(CROSS_CHAIN_PATH  ${ROOTPATH}/toolchain-sunxi-musl/toolchain/bin/)
set(CMAKE_C_COMPILER ${CROSS_CHAIN_PATH}arm-openwrt-linux-gcc)
set(CMAKE_CXX_COMPILER ${CROSS_CHAIN_PATH}arm-openwrt-linux-g++)
```

> 完整的 Tina Linux SDK 与工具链由 [LiThermal_Compiler](https://github.com/diylxy/LiThermal_Compiler) 仓库提供。`STAGING_DIR` 需指向 Tina SDK 的目标 staging 目录，以便链接 FFmpeg、rlottie 等预编译库。

## 2. CMake 构建脚本

顶层构建脚本 [CMakeLists.txt](file:///workspace/CMakeLists.txt) 要点：

| 配置项 | 说明 |
|--------|------|
| `CMAKE_POLICY_DEFAULT_CMP0077` | 允许子目录选项覆盖 |
| `file(GLOB_RECURSE SRC_DIR_LIST "src/*.cpp" "src/*.c")` | 自动收集 `src/` 下所有源文件 |
| `LV_CONF_INCLUDE_SIMPLE` | LVGL 配置包含方式 |
| `USE_SUNXIFB_DOUBLE_BUFFER / CACHE / G2D / G2D_ROTATE` | 启用全志 framebuffer 双缓冲、缓存、G2D 硬件加速与旋转 |
| `CONF_G2D_VERSION_NEW` | 使用新版 G2D 接口 |
| `-O2 -fpermissive -Wno-psabi` | 编译优化选项 |
| `LV_CONF_PATH` | 指向 `include/lv_conf.h` |

### 2.1 链接库

```cmake
target_link_libraries(${PROJECT_NAME}
    lvgl lv_drivers          # LVGL 及驱动
    uapi                     # 全志 UAPI
    avcodec avdevice avformat avfilter avutil swscale  # FFmpeg
    pthread                  # 线程
    rlottie                  # Lottie 动画

```

## 3. 编译步骤

### 3.1 使用 VSCode Tasks（推荐）

项目提供了 [.vscode/tasks.json](file:///workspace/.vscode/tasks.json)，包含三个任务：

1. **build**：配置 CMake 并编译
   ```bash
   export STAGING_DIR=/path/to/tina-sdk/out/t113-100ask/staging_dir/target
   cd ${workspaceFolder}/build
   cmake ${workspaceFolder} -DCMAKE_TOOLCHAIN_FILE=${workspaceFolder}/toolchain.cmake
   make -j32
   ```

2. **adb send**（依赖 build）：通过 adb 推送可执行文件到设备
   ```bash
   adb shell killall gdbserver
   adb shell killall thermalcamera
   adb push ${workspaceFolder}/build/thermalcamera /mnt/UDISK
   adb forward tcp:12345 tcp:12345
   ```

3. **adb run**（依赖 adb send）：在设备上启动 gdbserver 进行远程调试
   ```bash
   adb shell gdbserver 0.0.0.0:12345 /mnt/UDISK/thermalcamera
   ```

### 3.2 命令行手动编译

```bash
# 设置环境
export STAGING_DIR=/path/to/tina-sdk/out/t113-100ask/staging_dir/target
export ROOTPATH=/path/to/toolchain-parent  # toolchain.cmake 中 CROSS_CHAIN_PATH 依赖此变量

# 创建构建目录
mkdir -p build && cd build

# 配置（指定交叉工具链）
cmake .. -DCMAKE_TOOLCHAIN_FILE=../toolchain.cmake

# 编译
make -j$(nproc)
```

编译产物为 `build/LiThermal`（可执行文件）。

## 4. 部署到设备

### 4.1 通过 MTP（Windows）

将编译后的 `LiThermal`（或 `thermalcamera`）、`thermalcamera.sh`、`BSOD` 复制到设备的 MTP 存储中。

### 4.2 通过 ADB（跨平台）

```bash
adb push LiThermal /mnt/UDISK
adb push thermalcamera.sh /mnt/UDISK
adb push BSOD /mnt/UDISK
adb shell sync
adb shell reboot
```

## 5. 运行

设备重启后，启动脚本会自动运行 `/mnt/UDISK/thermalcamera`。程序流程参见 [系统架构 §5 启动流程](02-系统架构.md#5-启动流程)。

### 5.1 运行前提

- TF 卡已烧录 Tina Linux 系统镜像（`tina_t113-100ask_uart1.img`）
- STC8 单片机固件已烧录（电源管理）
- 海康 TB4117 已配置为 NCM 模式，IP 为 `192.168.64.64`，管理员密码 `Ab123456`
- 显示屏连接正常

## 6. 调试

### 6.1 GDB 远程调试

1. 本地执行 `adb run` 任务，在设备上启动 gdbserver。
2. 使用 VSCode 的 launch.json 配置远程 GDB 连接 `localhost:12345`。

### 6.2 串口日志

通过 `/dev/ttyS3` 可查看 STC8 单片机通信日志。主程序日志通过 `printf` 输出到标准输出（可通过 adb shell 查看）。

### 6.3 常见问题

- **白屏/黑屏/花屏**：检查 LCD 焊接与 framebuffer 驱动。
- **摄像头连不上**：确认 TB4117 已切换为 NCM 模式，IP 与密码正确，USB 线材尽量短且带屏蔽。
- **主菜单卡死**：更新到最新固件。
- **照片黑屏/无温度数据**：在 TB4117 Web 后台开启 Web 认证与测温规则。
