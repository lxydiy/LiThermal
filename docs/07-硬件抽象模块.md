# 07 · 硬件抽象模块

本文件介绍与硬件直接交互的模块：电源管理（通过 UART 与 STC8 单片机通信）和背光控制（通过 `/dev/disp` ioctl）。

---

## 1. 电源管理：PowerManager

源码：[src/PowerManager.cpp](file:///workspace/src/PowerManager.cpp)
声明：[include/my_main.h#L51-L54](file:///workspace/include/my_main.h#L51-L54)

### 1.1 职责

通过 UART 串口与 STC8 单片机通信，实现：
- 读取电池电压（ADC 采样）
- 检测充电状态
- 发送关机命令

### 1.2 串口配置

| 参数 | 值 |
|------|-----|
| 设备 | `/dev/ttyS3` |
| 波特率 | 115200 |
| 数据位 | 8 |
| 停止位 | 1 |
| 校验 | 无 |
| 流控 | 无 |
| 模式 | 原始（非规范）模式，VMIN=1, VTIME=0 |

### 1.3 串口命令协议

STC8 单片机接收 1 字节命令，返回相应数据：

| 命令宏 | 值 | 说明 | 返回 |
|--------|-----|------|------|
| `SERIAL_CMD_READ_ADC` | `0x58` | 读取电池 ADC 值 | 2 字节（高字节在前，uint16_t，单位 mV） |
| `SERIAL_CMD_POWEROFF` | `0x6a` | 请求关机 | 无 |
| `SERIAL_CMD_USBMODE_NORMAL` | `0x11` | USB 普通模式 | 无 |
| `SERIAL_CMD_USBMODE_WIFI_CAM` | `0x12` | USB WiFi 摄像头模式 | 无 |
| `SERIAL_CMD_USBMODE_DIRECT` | `0x13` | USB 直连模式 | 无 |
| `SERIAL_CMD_IS_CHARGING` | `0x59` | 查询充电状态 | 1 字节（1=充电中，0=未充电） |

### 1.4 关键函数

#### `int serialSetup()`

[PowerManager.cpp#L14-L74](file:///workspace/src/PowerManager.cpp#L14-L74)

打开 `/dev/ttyS3`，配置 termios 为 115200 8N1 原始模式，返回文件描述符。失败返回 -1。

#### `int16_t PowerManager_getBatteryVoltage()`

[PowerManager.cpp#L92-L121](file:///workspace/src/PowerManager.cpp#L92-L121)

1. 发送 `SERIAL_CMD_READ_ADC`
2. `tcflush` 清空缓冲区
3. `select` 等待 100ms 数据
4. 读取 2 字节，组合为 uint16_t（大端），返回电压值（mV）
5. 超时或错误返回 -1

#### `bool PowerManager_isCharging()`

[PowerManager.cpp#L123-L145](file:///workspace/src/PowerManager.cpp#L123-L145)

发送 `SERIAL_CMD_IS_CHARGING`，读取 1 字节，返回是否等于 1。

#### `void PowerManager_init()`

[PowerManager.cpp#L147-L150](file:///workspace/src/PowerManager.cpp#L147-L150)

调用 `serialSetup()` 初始化串口，保存到全局 `serial_fd`。

#### `void PowerManager_powerOff()`

[PowerManager.cpp#L153-L162](file:///workspace/src/PowerManager.cpp#L153-L162)

1. 发送 `SERIAL_CMD_POWEROFF` 给 STC8
2. `echo 1 > /tmp/poweroff`（标记关机状态）
3. `system("poweroff")` 执行 Linux 关机
4. `exit(0)`

### 1.5 调用关系

- `PowerManager_init()` 在 `HAL::init()` 中调用。
- `PowerManager_getBatteryVoltage()` / `PowerManager_isCharging()` 由 `battery_card_check()` 周期性调用。
- `PowerManager_powerOff()` 由 HAL 线程在 `global_poweroff_request` 为 true 时调用。

## 2. 背光控制：Backlight

源码：[src/Backlight.cpp](file:///workspace/src/Backlight.cpp)
声明：[include/my_main.h#L57-L59](file:///workspace/include/my_main.h#L57-L59)

### 2.1 职责

通过 `/dev/disp` 的 ioctl 接口控制 LCD 背光亮度，带 gamma 校正与平滑渐变。

### 2.2 硬件接口

- 设备：`/dev/disp`（全志显示设备）
- ioctl 命令：
  - `DISP_LCD_GET_BRIGHTNESS` — 获取当前背光值
  - `DISP_LCD_SET_BRIGHTNESS` — 设置背光值
- 头文件：[linux_include/sunxi_display2.h](file:///workspace/linux_include/sunxi_display2.h)

### 2.3 Gamma 校正

人眼对亮度的感知是非线性的，因此使用 256 项 gamma 查找表将线性亮度值（0~255）映射为硬件 PWM 值：

```cpp
static const uint8_t gamma_lut[256] = { ... };
```

该表在低亮度区间压缩、高亮度区间近似线性，使视觉亮度变化更均匀。

### 2.4 关键函数

#### `static int Backlight_getCurrent_internal()`

[Backlight.cpp#L36-L49](file:///workspace/src/Backlight.cpp#L36-L49)

通过 `DISP_LCD_GET_BRIGHTNESS` ioctl 获取原始 PWM 值，反向查找 gamma 表得到线性亮度值（0~255）。

#### `static void Backlight_setCurrent_internal(int new_backlight)`

[Backlight.cpp#L51-L61](file:///workspace/src/Backlight.cpp#L51-L61)

通过 `DISP_LCD_SET_BRIGHTNESS` ioctl 设置背光，`args[1] = gamma_lut[new_backlight]`。

#### `void *thread_backlight_func(void *param)`

[Backlight.cpp#L70-L91](file:///workspace/src/Backlight.cpp#L70-L91)

背光渐变线程，每 15ms 执行：
1. 比较 `current_backlight` 与 `globalSettings.brightness`
2. 逐步逼近（每次 ±1），实现平滑过渡
3. 调用 `ui_brightnessSlider_loop(current_backlight)` 更新亮度条 UI

#### `void Backlight_set(int new_backlight)`

[Backlight.cpp#L93-L98](file:///workspace/src/Backlight.cpp#L93-L98)

直接设置目标亮度（写入 `globalSettings.brightness`），由背光线程平滑过渡。

#### `void Backlight_step(int direction)`

[Backlight.cpp#L100-L116](file:///workspace/src/Backlight.cpp#L100-L116)

步进调节亮度（编码器旋转触发）：
- `direction > 0`：亮度 +8（上限 255）
- `direction < 0`：亮度 -8（下限 0）

#### `void Backlight_init()`

[Backlight.cpp#L118-L129](file:///workspace/src/Backlight.cpp#L118-L129)

1. 打开 `/dev/disp`
2. 读取当前背光值到 `current_backlight`
3. 创建 `thread_backlight` 线程

### 2.5 调用关系

- `Backlight_init()` 在 `HAL::init()` 末尾调用。
- `Backlight_step()` 由 HAL 线程在 `MODE_MAINPAGE` 模式下根据编码器方向调用。
- `Backlight_set()` 目前未在 UI 中直接调用（亮度通过编码器步进调节）。

### 2.6 全局变量

| 变量 | 类型 | 说明 |
|------|------|------|
| `backlight_fd` | `static int` | `/dev/disp` 文件描述符 |
| `current_backlight` | `int` | 当前实际背光值（0~255） |
| `globalSettings.brightness` | `uint32_t` | 目标亮度值 |
