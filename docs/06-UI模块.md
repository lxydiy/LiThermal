# 06 · UI 模块

本文件介绍所有用户界面模块，包括主菜单、相册、温度图表、准星、拍照录像、关机、电量卡片与亮度条。

UI 层基于 LVGL 8.x，所有控件操作需在 `LOCKLV()/UNLOCKLV()` 保护下进行。

---

## 1. 主菜单：button_2

源码：[src/ui/button_2.cpp](file:///workspace/src/ui/button_2.cpp)

### 1.1 职责

提供主界面弹出菜单，包含三个入口：相册、相机设置、系统设置。

### 1.2 菜单按钮（按键[1]）

`refresh_menu_key()` 由 HAL 线程每 25ms 调用，管理菜单展开/收起与模式切换：

- **MODE_MAINPAGE + 按键[1]**：展开主菜单，切换到 `MODE_MAINMENU`，卡片从 0×0 动画展开到 230×136。
- **菜单内选择**：编码器导航三个按钮，按 Enter（按键[3]）选择：
  - 0 → `MODE_GALLERY`，调用 `menu_gallery_show()`
  - 1 → `MODE_CAMERA_SETTINGS`，调用 `menu_basic_show()`
  - 2 → `MODE_SYSTEM_SETTINGS`，调用 `menu_system_show()`
- **再次按按键[1]**：收起菜单，返回 `MODE_MAINPAGE`。
- **子菜单中按按键[1]**：隐藏当前子菜单，返回主界面。

### 1.3 按钮样式

| 按钮 | 图标（FontAwesome） | 文字 | 聚焦色 |
|------|---------------------|------|--------|
| 相册 |  | 相册 | 0x0081B3（蓝） |
| 相机设置 |  | 相机设置 | 0xBB9100（金） |
| 系统设置 |  | 系统设置 | 0x960000（暗红） |

## 4. 相册：menu/gallery

源码：[src/ui/menu/gallery.cpp](file:///workspace/src/ui/menu/gallery.cpp)

### 4.1 职责

提供照片/视频的缩略图轮播、全屏查看与删除功能。

### 4.2 状态机

```
GALLERY_STATE_LIST          缩略图列表（默认）
    │ 按键[3](Enter)
    ▼
GALLERY_STATE_FULLSCREEN    全屏查看
    │ 按键[3]
    ▼
GALLERY_STATE_LIST

GALLERY_STATE_LIST
    │ 按键[2]
    ▼
GALLERY_STATE_MENU          删除确认菜单
    │ 编码器 / 按键[2]
    ▼
GALLERY_STATE_LIST
```

### 4.3 缩略图轮播

使用 5 个 `lv_obj` 容器（`image_obj[5]`）+ canvas 实现循环轮播，通过位运算管理"空闲槽位"：

- `image_pointer_left`：当前最左侧对象索引
- `image_spare_left`：左侧空闲对象数（图片不足 4 张时）
- 位置查找表 `image_pos_x_lut[4]` / `image_pos_y_lut[4]` / `image_fly_delay_lut[4]`

#### 滑动函数

| 函数 | 说明 |
|------|------|
| `image_obj_slide_left()` | 向右滑动（下一张），右侧对象移入 |
| `image_obj_slide_right()` | 向左滑动（上一张），左侧对象移入 |
| `image_obj_del_current()` | 删除当前图片，带动画 |
| `image_obj_close()` | 关闭相册，所有对象飞出动画 |

### 4.4 图片类型识别

`getPhotoType(int id)` 根据文件存在情况判断：

| 返回值 | 条件 | 说明 |
|--------|------|------|
| `PHOTO_TYPE_FILE_NOT_FOUND` | .jpeg 不存在 | — |
| `PHOTO_TYPE_RAW_CAPTURE` | .raw 存在 | 原始热成像照片（放大显示） |
| `PHOTO_TYPE_VIDEO` | .mjpeg 存在 | 视频（叠加 clapperboard 图标） |
| `PHOTO_TYPE_SCREENSHOT` | 仅 .jpeg 存在 | UI 截屏照片 |

### 4.5 全屏查看

`full_screen_show(int id)`：
- 照片：创建 canvas，将 JPEG 绘制到全屏（原始照片 2× 放大）
- 视频：创建 `lv_ffmpeg_player` 播放 `.mjpeg`，循环播放

### 4.6 删除

`createDeleteButton` 在当前图片上添加删除按钮，需点击两次确认（第一次变"确认删除"并加宽，第二次执行删除）。删除调用 `freeFileName(id)` + `system("rm CAPxxxxx.*")`。

### 4.7 关键函数

| 函数 | 说明 |
|------|------|
| `void menu_gallery_show()` | 进入相册：扫描文件、创建缩略图、显示文件计数 |
| `void menu_gallery_loop(bool has_hal_go_back_event)` | 相册主循环，处理编码器翻页、全屏切换、删除菜单 |

## 5. 温度曲线图：graph

源码：[src/ui/graph.cpp](file:///workspace/src/ui/graph.cpp)

### 5.1 职责

实时绘制最高/最低温度随时间变化的曲线，支持大/小尺寸、四象限位置、多种刷新间隔。

### 5.2 MyChart 类

自定义图表类，封装 LVGL `lv_chart`：

- 双曲线：蓝色（最低温）+ 红色（最高温）
- 数据范围 0~1000（温度 ×100）
- 余弦插值：当刷新间隔 > 更新间隔时，在两次采样间做余弦插值平滑曲线
- 自动 Y 轴范围：根据当前数据的 min/max 动态调整

#### 关键方法

| 方法 | 说明 |
|------|------|
| `init(parent, w, h, data_interval, default_value, callback, update_interval)` | 初始化图表，创建 LVGL timer |
| `destroy()` | 删除 timer 与控件 |
| `showLabel(show)` | 显示/隐藏数值标签 |
| `showTitle(title)` | 显示/隐藏标题 |
| `cosineInterpolation(data_buffer_ptr)` | 余弦插值计算 |

### 5.3 数据来源

```cpp
static uint16_t getGraphData(int id) {
    switch (id) {
        case GRAPH_DATA_SOURCE_MAX: return cameraUtils.lastResult.maxTemperature * 100;
        case GRAPH_DATA_SOURCE_MIN: return cameraUtils.lastResult.minTemperature * 100;
    }
}
```

### 5.4 刷新间隔

`graph_data_interval_table[7]` = {40, 100, 500, 1000, 2000, 5000, 10000} ms。

### 5.5 关键函数

| 函数 | 说明 |
|------|------|
| `void widget_graph_create()` | 创建图表卡片（默认隐藏在屏幕外） |
| `void widget_graph_updateSettings()` | 应用设置：尺寸、显示/隐藏、位置、刷新间隔 |
| `void widget_graph_check_visibility()` | 进入相册时自动隐藏，退出时恢复 |

## 6. 最值准星：crosshairs

源码：[src/ui/crosshairs.cpp](file:///workspace/src/ui/crosshairs.cpp)

### 6.1 职责

在屏幕上显示最高/最低温度点的准星图标与温度数值。

### 6.2 控件结构

|------|------|

## 7. 拍照与录像：camera

源码：[src/ui/camera.cpp](file:///workspace/src/ui/camera.cpp)

### 7.1 职责

实现拍照与录像功能，由按键事件触发。

### 7.2 拍照：`camera_take_photo_from_stream()`

[camera.cpp#L20-L39](file:///workspace/src/ui/camera.cpp#L20-L39)

- `preserveUI=false`：调用 `cameraUtils.readJpegWithExtra()` 获取带温度数据的 JPEG，保存 `.jpeg` + `.raw`。
- `preserveUI=true`：`lv_snapshot_take()` 截屏当前屏幕，用 `tiny_jpeg` 编码保存为 `.jpeg`。
- 调用 `flash_bang_effect()` 播放闪屏动画（白/黑半透明覆盖层淡出）。

### 7.3 录像：`camera_record_toggle_dump_stream()`

[camera.cpp#L45-L123](file:///workspace/src/ui/camera.cpp#L45-L123)

切换录像状态：
- **开始**：
  1. `readJpegWithExtra(name)` 保存首帧
  2. `codec_enablePacketDumping(true, "CAPxxxxx.mjpeg")` 开启 MJPEG 转储
  3. 删除同名 `.raw`（避免被识别为照片）
  4. 显示 Lottie REC 动画（5 秒后消失）
  5. 3 秒后创建闪烁红点 `circle_REC`（0.7s 周期淡入淡出）
- **停止**：
  1. 闪屏动画
  2. 删除红点与动画控件
  3. `codec_enablePacketDumping(false, NULL)` 关闭转储

## 8. 关机界面：poweroff

源码：[src/ui/poweroff.cpp](file:///workspace/src/ui/poweroff.cpp)

### 8.1 职责

长按关机键（按键[0]）时显示倒计时覆盖层，确认后执行关机。

### 8.2 流程

1. `refresh_poweroff_key()`（HAL 线程调用）检测 `key_pressed[0]`，调用 `lv_ui_poweroff()`。
2. 创建黑色半透明覆盖层 + "长按 N 秒后关机"提示卡片。
3. LVGL timer 每 25ms 递增 `animation_opa`（按住时），更新提示文字。
4. `animation_opa` 达到 255 时，显示"正在关机"，调用 `doPoweroff()`：
   - `settings_save()`
   - 设置 `global_poweroff_request = true`，由 HAL 线程延迟 500ms 后调用 `PowerManager_powerOff()`。
5. 松开按键时 `animation_opa` 快速递减，覆盖层消失。

## 9. 电量卡片：batteryCard

源码：[src/ui/batteryCard.cpp](file:///workspace/src/ui/batteryCard.cpp)

### 9.1 职责

在屏幕右上角显示电池电压与充电状态。

### 9.2 刷新逻辑

`battery_card_check()` 由 HAL 线程每 25ms 调用：
- 首次调用时创建卡片并从隐藏位置动画滑入。
- 每 20 次循环（约 500ms）读取一次电池电压与充电状态：
  - 电压：`PowerManager_getBatteryVoltage()`，显示为 `X.XXV`。
  - 充电：`PowerManager_isCharging()`，充电时卡片加宽并淡入闪电图标。

### 9.3 关键参数

| 参数 | 值 |
|------|-----|
| 卡片位置 | 右上角 (250, -13) |
| 默认宽度 | 56 |
| 充电宽度 | 56 + 12 |
| 隐藏 Y | -43（屏幕外） |

## 10. 亮度调节条：brightnessSlider

源码：[src/ui/brightnessSlider.cpp](file:///workspace/src/ui/brightnessSlider.cpp)

### 10.1 职责

在主界面旋转编码器调节亮度时，弹出亮度条实时反馈。

### 10.2 工作方式

- `ui_brightnessSlider_create()`：在 `lv_layer_sys` 创建 `lv_bar` 控件，初始隐藏在屏幕右侧外。
- `ui_brightnessSlider_loop(current_brightness)`：由背光线程每 15ms 调用：
  - 亮度变化时：滑入并显示当前值。
  - 1 秒无变化后：自动滑出隐藏。

### 10.3 与背光模块的关系

亮度值存储在 `globalSettings.brightness`，由 `Backlight_step(direction)` 修改（步进 8），背光线程平滑过渡实际背光并驱动此 UI。

## 11. 开机动画：boot_wait

源码：[src/boot_wait.cpp](file:///workspace/src/boot_wait.cpp)

### 11.1 职责

显示开机动画（Lottie）与进度条，等待摄像头连接并启动视频流。

### 11.2 流程

1. 显示 `bootlogo_full` 图片并淡出。
2. 若摄像头已连接，直接 `videoPlayer.init() + connect()` 并返回。
3. 否则创建进度条 + Lottie 动画，通过 timer 推进阶段：
   - **STAGE_WAIT_NCM**：等待 `usb0` 网卡出现，进度条 0→380。
   - **STAGE_WAIT_HTTP**：摄像头已连接，设置 IP，进度条 380→880，切换 Lottie 动画阶段。
   - **STAGE_FIN**：`videoPlayer.init() + connect()`，4 秒后删除动画控件。
