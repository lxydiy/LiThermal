# 05 · 视频与摄像头模块

本文件介绍视频播放（RTSP 拉流 + FFmpeg 解码）与摄像头控制（海康 ISAPI HTTP 接口）两大模块。

---

## 1. 视频编解码：videoCodec

源码：[src/videoCodec.cpp](file:///workspace/src/videoCodec.cpp)
头文件：[include/videoCodec.h](file:///workspace/include/videoCodec.h)

### 1.1 职责

封装 FFmpeg 库，提供 RTSP 流打开、MJPEG 解码、帧色彩空间转换，以及 MJPEG 录像（packet 直接转储，不重编码）。

### 1.2 依赖

```c
#include <libavcodec/avcodec.h>
#include <libswscale/swscale.h>
#include <libavformat/avformat.h>
#include <libavutil/imgutils.h>
```

### 1.3 全局状态

| 变量 | 类型 | 说明 |
|------|------|------|
| `input_ctx` | `AVFormatContext*` | 输入流上下文 |
| `output_ctx` | `AVFormatContext*` | 录像输出上下文 |
| `decoder_ctx` | `AVCodecContext*` | 解码器上下文 |
| `in_stream` / `out_stream` | `AVStream*` | 输入/输出视频流 |
| `sws_ctx` | `SwsContext*` | 色彩空间转换上下文 |
| `packet` | `AVPacket*` | 数据包 |
| `frame` | `AVFrame*` | 解码帧 |
| `video_stream_index` | `int` | 视频流索引 |
| `packet_dumping` | `bool` | 是否正在转储 packet（录像） |

### 1.4 关键函数

#### `bool codec_openStream(const char *url)`

[videoCodec.cpp#L85-L94](file:///workspace/src/videoCodec.cpp#L85-L94)

打开 RTSP 流的三步封装：
1. `openInputStream(url)` — `avformat_open_input` + `avformat_find_stream_info`，查找视频流索引。
2. `openInputDecoder()` — 查找 MJPEG 解码器，创建并打开 `decoder_ctx`。
3. `openMisc()` — 分配 `frame`、`packet`，创建 `sws_ctx`（解码格式 → BGRA，最近邻缩放）。

#### `AVFrame *codec_getFrame()`

[videoCodec.cpp#L190-L244](file:///workspace/src/videoCodec.cpp#L190-L244)

获取一帧解码后的图像（BGRA 格式）：
1. `av_read_frame` 读取 packet
2. 若 `packet_dumping` 为 true，调用 `av_write_frame` 将原始 MJPEG packet 写入录像文件
3. `avcodec_send_packet` → `avcodec_receive_frame` 解码
4. 分配 `scaled_frame`（BGRA），`sws_scale` 转换色彩空间
5. `av_packet_unref` 并返回 `scaled_frame`

> **注意**：调用方需 `av_frame_free` 释放返回的帧。

#### `void codec_enablePacketDumping(bool en, const char *dump_target)`

[videoCodec.cpp#L165-L188](file:///workspace/src/videoCodec.cpp#L165-L188)

开关 MJPEG 录像：
- 开启：`openOutputFile(dump_target)` 创建输出上下文，写入文件头。
- 关闭：写入剩余 packet + trailer，释放输出上下文。

录像采用 **packet 直接转储**（`avcodec_parameters_from_context(out_stream->codecpar, decoder_ctx)`），不进行重编码，性能开销极低。

#### `void codec_closeEverything()`

[videoCodec.cpp#L96-L120](file:///workspace/src/videoCodec.cpp#L96-L120)

释放所有 FFmpeg 资源（输入/输出上下文、解码器、帧、SWS 上下文）。

## 2. 视频播放：videoPlayer

源码：[src/videoPlayer.cpp](file:///workspace/src/videoPlayer.cpp)
头文件：[include/videoPlayer.h](file:///workspace/include/videoPlayer.h)

### 2.1 职责

管理 RTSP 视频流的连接、播放、暂停、断开，将解码帧渲染到 LVGL 图像控件。

### 2.2 类定义

```cpp
class VideoPlayer {
public:
    lv_obj_t *img_obj;        // LVGL 图像控件
    void init();              // 初始化网络 + 启动播放线程
    void connect();           // 发送连接命令
    void play();              // 发送播放命令
    void disconnect();        // 发送断开命令
};
extern VideoPlayer videoPlayer;
```

### 2.3 播放线程状态机

播放线程 `thread_refresh_image` 通过信号量 `sem_video` 与命令变量 `thread_video_command` 控制，状态机如下：

```
                ┌────────────┐
   sem_post ───▶│ STATE_IDLE │
                └─────┬──────┘
                      │ CMD_CONNECT 成功
                      ▼
                ┌──────────────┐
                │STATE_PLAYING │◄──── CMD_PLAY
                └──────┬───────┘
                       │ CMD_PAUSE
                       ▼
                ┌──────────────┐
                │STATE_PAUSED  │──── CMD_PLAY ──► STATE_PLAYING
                └──────────────┘
                       │ CMD_DISCONNECT
                       ▼
                STATE_IDLE
```

命令宏：`CMD_NONE` / `CMD_CONNECT` / `CMD_PLAY` / `CMD_PAUSE` / `CMD_DISCONNECT`。

### 2.4 关键函数

#### `void VideoPlayer::init()`

[videoPlayer.cpp#L167-L173](file:///workspace/src/videoPlayer.cpp#L167-L173)

- `sem_init(&sem_video, 0, 0)` — 初始信号量为 0
- `avformat_network_init()` — 初始化 FFmpeg 网络
- `pthread_create(thread_image_ref)` — 启动播放线程

#### `void *thread_refresh_image(void *)`

[videoPlayer.cpp#L54-L165](file:///workspace/src/videoPlayer.cpp#L54-L165)

核心播放循环：
- **CMD_CONNECT**：调用 `codec_openStream(VIDEO_STREAM_URL)`，失败则重试；成功后创建 LVGL 图像控件并淡入。
- **STATE_PLAYING**：循环调用 `codec_getFrame()`，将 BGRA 数据拷贝到 `IR_frame_buffer`，调用 `lv_obj_invalidate` 触发重绘。连续 10 次空帧则断开重连。
- **CMD_DISCONNECT**：销毁图像控件，调用 `codec_closeEverything()`。

### 2.5 帧缓冲区

```cpp
uint8_t IR_frame_buffer[320 * 240 * 4];   // BGRA 格式
static lv_img_dsc_t img_ir_frame;         // LVGL 图像描述符
```

解码帧通过 `av_image_copy_to_buffer` 拷贝到 `IR_frame_buffer`，LVGL 图像控件直接引用此缓冲区。

## 3. 摄像头控制：cameraUtils

源码：[src/cameraUtils.cpp](file:///workspace/src/cameraUtils.cpp)
头文件：[include/cameraUtils.h](file:///workspace/include/cameraUtils.h)

### 3.1 职责

通过海康 ISAPI（HTTP）接口控制 TB4117 热成像模组：连接检测、温度获取、调色板切换、降噪、细节增强、中心测温、手动校准、最值准星、拍照（带温度数据）。

### 3.2 通信方式

- HTTP 客户端：[httplib](file:///workspace/include/httplib.h)（header-only）
- 基础认证：用户名 `admin`，密码 `Ab123456`
- 摄像头地址：`http://192.168.64.64`

### 3.6 关键函数详解

#### `bool checkCameraConnection()`

[cameraUtils.cpp#L11-L24](file:///workspace/src/cameraUtils.cpp#L11-L24)

读取 `/proc/net/dev`，检查是否包含 `usb0` 网卡，判断 TB4117（NCM 模式）是否已连接。

#### `void getTemperature()`

[cameraUtils.cpp#L37-L90](file:///workspace/src/cameraUtils.cpp#L37-L90)

GET `/ISAPI/Thermal/channels/1/thermometry/1/rulesTemperatureInfo?format=json`

使用 cJSON 解析返回的 JSON，提取 max/min/average 温度及最值点坐标，存入 `lastResult`。

#### `void setColorPalette(int palette)`

[cameraUtils.cpp#L110-L118](file:///workspace/src/cameraUtils.cpp#L110-L118)

PUT `/ISAPI/Image/channels/1/Palettes`，XML body 中 `<mode>` 为调色板名称字符串。

#### `float readJpegWithExtra(save_filename, result_x, result_y)`

[cameraUtils.cpp#L202-L237](file:///workspace/src/cameraUtils.cpp#L202-L237)

GET `/ISAPI/Thermal/channels/1/thermometry/jpegPicWithAppendData?format=json`

返回 multipart 响应，包含三部分：
1. JSON 元数据
2. JPEG 图像数据
3. 原始温度矩阵数据（每像素 4 字节 float，160×120）

若 `save_filename` 非空，将第 2、3 部分分别保存为 `.jpeg` 与 `.raw`。返回 `(result_x, result_y)` 处的中心温度。

#### `void set4117Cursor(bool min, bool max)`

[cameraUtils.cpp#L260-L315](file:///workspace/src/cameraUtils.cpp#L260-L315)

先 GET `/ISAPI/Thermal/channels/1/thermometry/basicParam` 获取当前 XML，逐行替换 `<displayMaxTemperatureEnabled>` / `<displayMinTemperatureEnabled>` / `<enabled>` / `<streamOverlay>` 节点，再 PUT 回去。
