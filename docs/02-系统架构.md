# 02 · 系统架构

## 1. 分层架构

项目采用分层设计，自底向上分为四层：

```
┌─────────────────────────────────────────────┐
│              应用层 (Application)            │
│   主菜单 / 相册 / 图表 / 准星 / 拍照录像      │
├─────────────────────────────────────────────┤
│              UI 层 (LVGL)                    │
│   控件渲染 / 动画 / 事件 / 输入设备           │
├─────────────────────────────────────────────┤
│              业务逻辑层 (Logic)               │
│   摄像头控制 / 视频解码 / 设置存储 / 电源      │
├─────────────────────────────────────────────┤
│              硬件抽象层 (HAL)                 │
│   Framebuffer / 输入设备 / UART / DISP ioctl  │
└─────────────────────────────────────────────┘
```

- **硬件抽象层**：`myHAL.cpp`、`PowerManager.cpp`、`Backlight.cpp`。负责初始化显示（sunxifb）、读取编码器/按键（Linux input）、与 STC8 单片机串口通信（电源/电池）、控制背光（`/dev/disp` ioctl）。
- **业务逻辑层**：`cameraUtils.cpp`（摄像头 ISAPI 控制）、`videoCodec.cpp`（FFmpeg 解码）、`videoPlayer.cpp`（播放线程）、`settingsStorage.cpp`（设置持久化）、`filenameAllocator.cpp`（文件名分配）。
- **UI 层**：基于 LVGL 8.x，包含所有界面控件、动画与交互。
- **应用层**：状态机驱动的界面切换，由 `current_mode` 枚举统一调度。

## 2. 线程模型

程序采用多线程架构，LVGL 的 UI 操作通过互斥锁 `lv_mutex` 保护。

```
main()
 ├── thread_ui        → lv_task_handler() 循环，处理 LVGL 渲染与事件
 ├── thread_app       → 热成像刷新线程：温度轮询、设置同步、准星更新
 └── HAL::init()
      ├── thread_hal           → 按键/编码器事件处理、菜单/相册循环、电量刷新、关机
      ├── thread_key           → 读取物理按键 (/dev/input/event2)
      ├── thread_encoder       → 读取旋转编码器 (/dev/input/event0)
      └── thread_backlight     → 背光渐变调节
 └── videoPlayer::init()
      └── thread_image_ref     → RTSP 拉流 + FFmpeg 解码 + 帧渲染
```

### 2.1 线程职责

| 线程 | 创建位置 | 职责 |
|------|----------|------|
| `thread_ui` | [main.cpp#L82](file:///workspace/src/main.cpp#L82) | LVGL 主循环，调用 `lv_task_handler()` |
| `thread_app` | [main.cpp#L84](file:///workspace/src/main.cpp#L84) | 等待摄像头连接后，轮询温度、同步设置到摄像头、更新准星 |
| `thread_hal` | [myHAL.cpp#L231](file:///workspace/src/myHAL.cpp#L231) | 处理按键事件、菜单状态机、相册循环、电池刷新、关机 |
| `thread_key` | [myHAL.cpp#L135](file:///workspace/src/myHAL.cpp#L135) | 阻塞读取按键事件，更新 `key_pressed`/`key_press_event` |
| `thread_encoder` | [myHAL.cpp#L136](file:///workspace/src/myHAL.cpp#L136) | 阻塞读取编码器事件，累加 `encoder_new_move` |
| `thread_backlight` | [Backlight.cpp#L127](file:///workspace/src/Backlight.cpp#L127) | 平滑调节背光，驱动亮度条 UI |
| `thread_image_ref` | [videoPlayer.cpp#L172](file:///workspace/src/videoPlayer.cpp#L172) | RTSP 连接、拉流、解码、渲染到 LVGL 图像控件 |

### 2.2 LVGL 互斥锁

所有 LVGL 对象操作必须在持有 `lv_mutex` 时进行，通过宏 `LOCKLV()` / `UNLOCKLV()` 包裹：

```c
#define LOCKLV()   pthread_mutex_lock(&lv_mutex)
#define UNLOCKLV() pthread_mutex_unlock(&lv_mutex)
```

详见 [my_main.h#L44-L45](file:///workspace/include/my_main.h#L44-L45)。

## 3. 数据流向

### 3.1 视频流显示

```
TB4117 (RTSP MJPEG)
    │  rtsp://admin:Ab123456@192.168.64.64

    ▼
```

```
TB4117 ISAPI

    │  cameraUtils.getTemperature()
```

### 3.3 拍照流程

```
按键 [3] (Enter) 按下
    │  HAL::key_press_event[3]

    │
    ├─ preserveUI=false → cameraUtils.readJpegWithExtra()

    │      保存 CAPxxxxx.jpeg + CAPxxxxx.raw
    │
    └─ preserveUI=true  → lv_snapshot_take() + tiny_jpeg 编码
           保存 CAPxxxxx.jpeg (含 UI 截屏)
    ▼
flash_bang_effect()  闪屏动画
```

### 3.4 录像流程

```
按键 [2] 按下 (切换)
    │
    ▼
camera_record_toggle_dump_stream()  [camera.cpp]
    │
    ├─ 开始：readJpegWithExtra(首帧) → codec_enablePacketDumping(true, file.mjpeg)
```

## 4. 运行模式状态机

系统通过全局变量 `current_mode`（类型 `current_mode_t`）管理界面状态，定义于 [myHAL.h#L12-L19](file:///workspace/include/myHAL.h#L12-L19)：

```
                    ┌──────────────┐
                    │ MODE_MAINPAGE│  主界面（实时热成像）
                    └──────┬───────┘
                           │ 按键[1](菜单键)
                           ▼
                    ┌──────────────┐
              ┌────▶│ MODE_MAINMENU│  主菜单（相册/相机设置/系统设置）
              │     └──────┬───────┘
              │            │
       选择相册│     选择相机设置│      选择系统设置
              ▼            ▼                 ▼
     ┌────────────┐  ┌──────────────┐  ┌──────────────────┐
     │MODE_GALLERY│  │MODE_CAMERA_  │  │MODE_SYSTEM_      │
     │_MENU       │  │SETTINGS      │  │SETTINGS          │
     └─────┬──────┘  └──────────────┘  └──────────────────┘
           │ 按键[1]返回
           ▼
     ┌────────────┐
     │MODE_GALLERY│  相册（缩略图轮播）
     └─────┬──────┘
           │ 按键[3](Enter)
           ▼
     ┌──────────────────┐
     │GALLERY_STATE_    │  全屏查看（照片/视频）
     │FULLSCREEN        │
     └──────────────────┘
```

### 模式枚举

| 枚举值 | 含义 |
|--------|------|
| `MODE_MAINPAGE` | 主界面：显示实时热成像，编码器调亮度 |
| `MODE_MAINMENU` | 主菜单弹出：相册 / 相机设置 / 系统设置 |
| `MODE_GALLERY` | 相册缩略图列表 |
| `MODE_GALLERY_MENU` | 相册删除确认菜单 |
| `MODE_CAMERA_SETTINGS` | 相机设置（调色板、准星、图表等） |
| `MODE_SYSTEM_SETTINGS` | 系统设置（保留 UI、内置准星、手动校准、恢复默认） |

## 5. 启动流程

```
main()
  ├── sleep(1)                              // 等待系统稳定
  ├── mkdir GALLERY_PATH                    // 创建相册目录
  ├── pthread_mutex_init(&lv_mutex)         // 初始化 UI 锁
  ├── HAL::init()
  │     ├── PowerManager_init()             // 打开串口 /dev/ttyS3
  │     ├── settings_load()                 // 读取 /mnt/UDISK/settings.dat
  │     ├── lv_init()                       // LVGL 初始化
  │     ├── sunxifb_init()                  // 全志 framebuffer
  │     ├── lv_disp_drv_register()          // 注册显示驱动 (320x240)
  │     ├── initInputDevices()              // 编码器 + 按键输入设备
  │     ├── signal(SIGINT, signal_exit)     // 退出信号处理
  │     ├── pthread_create(thread_hal)      // HAL 事件处理线程
  │     └── Backlight_init()                // 背光初始化 + 线程
  ├── readFiles(GALLERY_PATH)               // 扫描相册文件，构建位图
  ├── waitboot_scr_load()                   // 开机动画 + 等待摄像头连接
  │     └── videoPlayer.init() + connect()  // 启动 RTSP 播放线程
  ├── widget_graph_create()                 // 创建温度曲线图
  ├── ui_crosshairs_create()                // 创建最值准星
  ├── pthread_create(thread_ui)             // LVGL 主循环线程
  ├── cameraUtils.initHTTPClient()          // 设置 HTTP Basic Auth
  ├── pthread_create(thread_app)            // 热成像刷新线程
  └── pthread_join(thread_ui)               // 等待 UI 线程结束
```
