# LiThermal 代码 Wiki

> LiThermal 是一款基于全志 T113-S3 主控 + 海康威视 TB4117 热成像模组的开源热成像相机项目。

本 Wiki 系统梳理项目的整体架构、模块职责、关键类与函数、依赖关系以及运行方式，作为代码阅读与二次开发的参考手册。
