# 01 · 项目概述

## 1. 项目简介

**LiThermal** 是一款开源热成像相机项目，核心由一块全志（Allwinner）**T113-S3** ARM Linux 开发板驱动，外接海康威视 **TB4117** 热成像模组（通过 USB NCM / UVC 模式连接）。设备提供 320×240 显示屏，实时显示热成像画面，支持拍照、录像（MJPEG）、温度曲线图表、最值/中心值准星、亮度调节、相册回放等功能。

- 项目名：`LiThermal`
- 开源协议：GPL 3.0
- 作者：小李电子实验室
- 主控：全志 T113-S3（双核 ARM Cortex-A7，运行 Tina Linux / OpenWrt musl 工具链）
- 显示屏：320×240 LCD，通过 sunxi framebuffer 驱动
- 热成像模组：海康 TB4117（RTSP 视频流 + ISAPI HTTP API）
- UI 框架：LVGL 8.x
- 视频处理：FFmpeg（libavcodec / libavformat / libswscale）
- 动画：rlottie（Lottie 矢量动画）

## 2. 硬件组成

| 模块 | 说明 | 通信方式 |
|------|------|----------|
| T113-S3 主控 | 运行 Linux 系统，承担 UI 渲染与视频解码 | — |
| 320×240 LCD | 显示热成像画面与 UI | sunxi framebuffer (`/dev/disp`) |
| 海康 TB4117 | 热成像采集，输出 RTSP 流 | USB NCM（以太网 over USB） |
| STC8 单片机 | 电源管理、ADC 电池电压采样、充电检测 | UART (`/dev/ttyS3`, 115200 bps) |
| 旋转编码器 | 菜单导航 / 亮度调节 | Linux input (`/dev/input/event0`) |
| 物理按键 ×3 | 关机键、菜单键、拍照/录像键 | Linux input (`/dev/input/event2`) |
| TF 卡 | 存储照片/视频/设置 | `/mnt/UDISK` |

## 5. 核心功能

- **实时热成像显示**：通过 RTSP 拉取 MJPEG 流，FFmpeg 解码为 BGRA，经 LVGL `lv_img` 渲染到 320×240 屏幕。
- **拍照**：调用摄像头 `jpegPicWithAppendData` 接口获取带温度数据的 JPEG，保存为 `.jpeg` + `.raw`（原始温度矩阵）。
- **录像**：将 MJPEG packet 直接写入 `.mjpeg` 文件（不重编码）。
- **温度测量**：通过 ISAPI 获取画面最高/最低/平均温度及坐标，在屏幕上显示准星与数值。
- **温度曲线图**：实时绘制最高/最低温度随时间变化曲线，支持余弦插值。
- **调色板切换**：15 种伪彩调色板（白热、黑热、融合、彩虹、铁红等）。
- **相册**：5 张缩略图轮播、全屏查看（照片/视频）、删除。
- **亮度调节**：编码器旋转调节屏幕背光，带 gamma 校正。
- **电量显示**：通过 STC8 单片机读取电池电压与充电状态。
