## 1. 程序入口：main.cpp

源码：[src/main.cpp](file:///workspace/src/main.cpp)

### 1.1 职责

程序的主入口，负责：
- 初始化互斥锁与 HAL
- 扫描相册文件
- 加载开机动画
- 创建 UI 线程与热成像刷新线程
- 启动视频播放

### 1.2 关键函数

#### `int main()`

[main.cpp#L68-L88](file:///workspace/src/main.cpp#L68-L88)

```
1. sleep(1)                        // 等待系统稳定

8. widget_graph_create()           // 创建温度曲线图

12. pthread_create(thread_app)     // 启动热成像刷新线程

```

#### `void *thread_app_func(void *)`

[main.cpp#L6-L62](file:///workspace/src/main.cpp#L6-L62) — 热成像刷新线程

- 等待 `cameraUtils.connected` 为 true

- 在 `MODE_MAINPAGE` / `MODE_CAMERA_SETTINGS` 模式下每 40ms 调用 `cameraUtils.getTemperature()` 拉取温度
- 更新准星位置与图表可见性

#### `void *thread_ui_func(void *)`

[main.cpp#L63-L67](file:///workspace/src/main.cpp#L63-L67) — UI 线程，调用 `HAL::lv_loop()`。

## 2. 硬件抽象层：myHAL

源码：[src/myHAL.cpp](file:///workspace/src/myHAL.cpp)
头文件：[include/myHAL.h](file:///workspace/include/myHAL.h)

### 2.1 职责

- 初始化 LVGL 与全志 framebuffer 显示驱动
- 初始化输入设备（编码器 + 按键）
- 提供 LVGL 主循环 `lv_loop()`
- HAL 线程处理按键事件分发、菜单状态机、相册循环、电量刷新、关机

### 2.2 命名空间 `HAL`

```cpp
namespace HAL {
    extern bool key_pressed[3];          // 3 个按键当前按下状态
    extern time_t key_pressed_start_time[3];  // 按下起始时间（不含 Enter）
    extern bool key_press_event[4];      // 4 个按键的一次性事件标志（含 Enter）
    void init();
    void lv_loop();
}
```

### 2.3 关键函数

#### `void HAL::init()`

[myHAL.cpp#L187-L234](file:///workspace/src/myHAL.cpp#L187-L234)

初始化流程：
1. `PowerManager_init()` — 打开串口
2. `settings_load()` — 加载设置
3. `lv_init()` — LVGL 初始化
4. `sunxifb_init(rotated)` — 初始化全志 framebuffer
5. 分配绘制缓冲（320×240×4 字节，BGRA）
6. 注册显示驱动，`flush_cb = sunxifb_flush`
7. `initInputDevices()` — 注册编码器输入设备 + 启动按键/编码器读取线程
8. 注册 `SIGINT` 信号处理（保存设置、断开视频、退出）
9. 创建 `thread_hal` 线程
10. `Backlight_init()` — 背光初始化

#### `void HAL::lv_loop()`

[myHAL.cpp#L236-L245](file:///workspace/src/myHAL.cpp#L236-L245)

LVGL 主循环，在持有 `lv_mutex` 时调用 `lv_task_handler()`，每 5ms 一次。

#### `static void *thread_refreshKey(void *)`

[myHAL.cpp#L43-L79](file:///workspace/src/myHAL.cpp#L43-L79)

阻塞读取 `/dev/input/event2` 的按键事件：
- `KEY_ENTER` → `key_press_event[3]`（拍照键）
- `KEY_F1` / `KEY_F2` / `KEY_F3` → `key_pressed[0..2]` 与 `key_press_event[0..2]`

#### `static void *thread_refreshEncoder(void *)`

[myHAL.cpp#L81-L99](file:///workspace/src/myHAL.cpp#L81-L99)

阻塞读取 `/dev/input/event0` 的相对事件，累加到 `encoder_new_move`（方向反转）。

#### `static void encoder_read(lv_indev_drv_t *drv, lv_indev_data_t *data)`

[myHAL.cpp#L101-L121](file:///workspace/src/myHAL.cpp#L101-L121)

LVGL 编码器读取回调。仅在非主界面/非相册模式下将编码器事件传给 LVGL（主界面用于亮度调节，相册用于翻页，由 HAL 线程直接处理）。

#### `void *thread_hal_func(void *)`

[myHAL.cpp#L139-L185](file:///workspace/src/myHAL.cpp#L139-L185)

HAL 核心事件循环，每 25ms 执行一次：
- `refresh_poweroff_key()` — 处理关机长按
- 若 `global_poweroff_request`，延迟 500ms 后调用 `PowerManager_powerOff()`
- `MODE_MAINPAGE`：编码器调亮度、按键[2]录像、按键[3]拍照
- `MODE_GALLERY` / `MODE_GALLERY_MENU`：调用 `menu_gallery_loop(false)`
- `refresh_menu_key()` — 菜单键处理与模式切换
- `battery_card_check()` — 电量刷新

#### `void signal_exit(int signo)`

[myHAL.cpp#L33-L41](file:///workspace/src/myHAL.cpp#L33-L41)

Ctrl+C 退出处理：`sunxifb_exit()`、保存设置、断开视频流、退出。

## 3. 设置存储：settingsStorage

源码：[src/settingsStorage.cpp](file:///workspace/src/settingsStorage.cpp)
头文件：[include/settingsStorage.h](file:///workspace/include/settingsStorage.h)

### 3.1 职责

将用户设置（亮度、调色板、图表、准星等）以二进制结构体形式持久化到 `/mnt/UDISK/settings.dat`。

### 3.2 数据结构

```c
typedef struct settingsStorage_t {
    uint32_t __head;                     // 魔数头 0x80000001
    uint32_t brightness;                 // 背光亮度 0-255
    uint32_t colorPalette;               // 调色板索引
    uint32_t enableGraph;                // 是否显示温度曲线图
    uint32_t graphPos;                   // 图表位置（0=左上 1=右上 2=右下 3=左下）
    uint32_t graphSize;                  // 图表尺寸（0=小 1=大）
    uint32_t graphRefreshInterval;       // 图表刷新间隔索引
    uint32_t enableMaxValueDisplay;      // 显示最大值准星
    uint32_t enableMinValueDisplay;      // 显示最小值准星
    uint32_t enableCenterValueDisplay;   // 显示中心温度
    uint32_t preserveUI;                 // 拍照保留 UI（截屏模式）
    uint32_t useBlackFlashBang;          // 拍照闪屏反色（黑色）
    uint32_t use4117Cursors;             // 使用 4117 内置准星
    uint32_t __tail;                     // 魔数尾 0x1715600D
} settingsStorage_t;
```

通过 `__head` 与 `__tail` 魔数校验文件完整性。

### 3.3 全局实例

```cpp
settingsStorage_t globalSettings;
```

### 3.4 关键函数

| 函数 | 说明 |
|------|------|
| `void settings_default()` | 填充默认值（亮度 170、调色板 Fusion1、中心值开启等） |
| `void settings_load()` | 从文件读取，校验头尾魔数，损坏则重置为默认 |
| `void settings_save()` | 写入文件 |

### 3.5 默认值

| 字段 | 默认值 |
|------|--------|
| brightness | 170 |
| colorPalette | `IR_COLOR_PALETTE_FUSION1` (2) |
| enableCenterValueDisplay | true |
| 其余 | false / 0 |

源码：[src/animations.cpp](file:///workspace/src/animations.cpp)

### 4.1 职责

提供自定义缓动函数与一组 LVGL 动画封装，以及通用的卡片容器类 `MyCard`。

### 4.2 自定义缓动曲线

| 函数 | 说明 |
|------|------|
| `my_ease_bounce_back(t)` | 带回弹的 ease out |
| `my_ease_out(t)` | `1-(1-t)³` |
| `my_ease_in(t)` | `t⁴` |
| `easeInOutQuart(t)` | 四阶 ease in-out |
| `my_anim_path_ease_in/out/in_out(a)` | LVGL 路径回调封装 |

### 4.3 动画封装函数

| 函数 | 说明 |
|------|------|
| `lv_my_anim_pop_up(obj, time, delay)` | 弹出动画（带旋转与回弹），**禁止修改 obj 的 userdata** |
| `lv_my_anim_fall_down(obj, time, delay, del)` | 掉落动画，`del=true` 结束后删除对象 |
| `lv_anim_move(obj, x, y, time, delay)` | 位置动画（ease out） |
| `lv_anim_size(obj, w, h, time, delay)` | 尺寸动画（ease out） |

### 4.4 卡片类 MyCard

`MyCard` 是一个带进出动画的 LVGL 容器封装，用于菜单、电量卡片等弹出式面板。

```cpp
class MyCard {
public:
    lv_obj_t *obj = NULL;
    void create(parent, x, y, w, h, align);   // 创建容器
    void show(anim_type);                      // 显示（支持 NONE/POP_UP/FLY_UP）
    void hide(anim_type);                      // 隐藏
    void size(w, h, animated);                 // 调整尺寸
    void move(x, y, animated);                 // 移动
    void del(anim_type);                       // 删除（带动画）
};
```

动画类型宏：`CARD_ANIM_NONE`、`CARD_ANIM_POP_UP`、`CARD_ANIM_FLY_UP`、`CARD_ANIM_FALL_DOWN`、`CARD_ANIM_FLY_DOWN`。

## 5. 文件名分配器：filenameAllocator

源码：[src/utils/filenameAllocator.cpp](file:///workspace/src/utils/filenameAllocator.cpp)
头文件：[include/utils/filenameAllocator.h](file:///workspace/include/utils/filenameAllocator.h)

### 5.1 职责

管理相册中照片/视频文件名的分配与回收。文件命名格式为 `CAP%05d.[jpeg/raw/mjpeg]`，ID 范围 0~99999。

### 5.2 实现原理

使用位图（bitmap）记录已占用的 ID：

```cpp
#define GALLERY_MAX_IMAGES 100000  // 必须为 8 的倍数
static uint8_t image_hashmap[GALLERY_MAX_IMAGES / 8];  // 每 bit 代表一个 ID
```

通过位运算高效判断与分配 ID。

### 5.3 关键函数

| 函数 | 说明 |
|------|------|
| `void readFiles(const char *dirToOpen)` | 扫描目录，解析 `CAPxxxxx.ext` 文件名，填充位图 |
| `int getTotalImages()` | 统计位图中置位的 bit 总数（使用 256 项查表计数） |
| `int getLastImageID()` | 返回最大已用 ID + 1（即下一个可用 ID） |
| `int getNextImage(int current)` | 向后查找下一张图片 ID，循环 |
| `int getPrevImage(int current)` | 向前查找上一张图片 ID，循环 |
| `const char *allocateNewFilename()` | 分配新文件名（格式 `GALLERY_PATH/CAP%05d`），返回静态缓冲区指针 |
| `void freeFileName(int id)` | 释放指定 ID（删除图片时调用） |

### 5.4 注意事项

- `allocateNewFilename()` 返回的是静态缓冲区指针，调用方需立即使用或复制。
- `readFiles()` 在 `main()` 启动时调用一次，相册进入时也会调用以刷新。
